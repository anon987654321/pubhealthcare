# AI3 Assistants

This directory contains specialized AI assistant implementations for various domains.

## Available Assistants

- **advanced_propulsion.rb** - Advanced propulsion engineering assistant
- **architect.rb** - Parametric architecture design assistant  
- **hacker.rb** - Ethical hacking assistant
- **healthcare.rb** - Healthcare and medical assistant
- **lawyer.rb** - Legal consultation assistant
- **openbsd_driver_translator.rb** - OpenBSD driver translation assistant
- **material_science.rb** - Materials science assistant
- **medical_doctor.rb** - Medical doctor assistant
- **offensive_operations.rb** - Offensive operations assistant
- **personal_assistant.rb** - Personal protection assistant
- **propulsion_engineer.rb** - Propulsion engineering assistant
- **real_estate.rb** - Real estate assistant
- **rocket_scientist.rb** - Rocket science assistant
- **seo.rb** - SEO specialist assistant
- **sound_mastering.rb** - Audio mastering assistant
- **sys_admin.rb** - System administration assistant
- **trader.rb** - Trading and financial assistant
- **web_developer.rb** - Web development assistant

## Subdirectories

- **multimedia/** - Multimedia processing tools and integrations
  - **replicate.rb** - Replicate API integration for multimedia

## Usage

Each assistant can be loaded and used independently or as part of the AI3 orchestration system.
